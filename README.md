# Interactive Comments Section

Интерактивная секция комментариев, созданная по заданию [Frontend Mentor](https://www.frontendmentor.io/challenges/interactive-comments-section-iG1RugEG9). Это учебный проект на React с сохранением изменений через MockAPI.

## Возможности

- Просмотр комментариев и ответов.
- Добавление комментариев и ответов на выбранный комментарий.
- Редактирование и удаление своих сообщений; перед удалением появляется подтверждение.
- Голосование за комментарии и ответы: один голос со значением `-1`, `0` или `+1` для каждого сообщения.
- Сохранение комментариев, ответов и голосов через API.

## Технологии

- React и JavaScript.
- CSS.
- Vite.
- Fetch API и MockAPI.

## Запуск локально

Установите зависимости и запустите сервер разработки:

```bash
npm install
npm run dev
```

Адрес приложения появится в терминале после запуска.

Чтобы проверить производственную сборку:

```bash
npm run build
```

## Как хранятся данные

Приложение получает данные из двух ресурсов MockAPI:

- `comments` — комментарии; ответы находятся в массиве `replies` соответствующего комментария.
- `currentUser` — демонстрационный пользователь и его голоса в массиве `votes`.

Для загрузки используются `GET`-запросы. Новый комментарий создаётся через `POST /comments`; изменения комментария или его ответов сохраняются через `PUT /comments/:id`; удаление комментария выполняется через `DELETE /comments/:id`. Голоса пользователя сохраняются через `PUT /currentUser/1`.

Файл `data.json` содержит исходные данные задания. Работающее приложение получает данные из MockAPI.

Это демонстрационный проект с одним общим пользователем, без регистрации и отдельного аккаунта для каждого посетителя. Изменения в API видны всем, кто откроет приложение.
